# 틈틈이 큐브

손으로 돌리는 3D 큐브 — 튜토리얼 · 일반 · 오늘의 챌린지

- 웹: https://every-cube.ohsangplay.com
- 번들 ID / 패키지명: `com.ohsang.play.cube`

## 구조

| 경로 | 내용 |
|---|---|
| `src/src.html` | 화면·게임 코드 (Three.js) |
| `src/hint-engine.js` | 조각 단위 힌트 엔진 (초보자 7단계) |
| `src/guide.js` | 튜토리얼 공략 문구 |
| `index.html` | 위 세 파일을 합친 결과물 (`python3 src/build.py`) |
